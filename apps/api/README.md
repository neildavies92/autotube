# AutoTube API

Go API service for the local-first AutoTube MVP.

This scaffold intentionally starts with the Go standard library:

- `net/http` and `http.ServeMux` for routing
- `log/slog` for structured logs
- `database/sql` for PostgreSQL access
- `http.Server` timeouts and graceful shutdown
- `httptest` for handler tests

PostgreSQL uses the `github.com/lib/pq` driver. Type-safe query code is generated by `sqlc` into `apps/api/internal/storage/db`.

Configuration is loaded from environment variables in `internal/config`.
`AUTOTUBE_HTTP_ADDR` defaults to `:8080`, while provider-backed workflows can explicitly require provider secrets before they run.

External integrations start as interfaces in `internal/providers` for YouTube, trends, LLM, image, voice, rendering, and upload providers. Background work starts as contracts in `internal/workflow`; durable queue infrastructure remains deferred until a real asynchronous workflow needs it.

Run from the repository root:

```bash
npm run dev:api
```

Test from the repository root:

```bash
npm run test:api
```

Create a local database from scratch:

```bash
make db-reset
```
